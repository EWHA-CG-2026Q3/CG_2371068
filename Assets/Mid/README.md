# The Silent Pavilion — 침묵의 정자

늦은 밤 숲속 정자에 접근하면 기존 벤치에 앉은 뒤틀린 나무형 크리처가 서서히 드러나는 1인칭 탐색 장면입니다. 상체 호흡과 흔들림, 떠다니는 불빛, 낮은 안개와 짧은 화면 잡음으로 불길한 분위기를 만듭니다.

현재 단계는 **중간 과제용 기능 구현·장면 배치를 마친 1차 완성본**입니다. 화면 밝기와 착석 배치를 사용자 피드백으로 보완했으며, 기말용 콘텐츠와 렌더링 확장은 아래 계획에 남아 있습니다.

## 현재 적용된 수정

- 크리처를 매끈한 인체에서 갈라진 줄기·빈 몸통·비틀린 팔다리·가지 손가락·수관 형태의 머리로 변경했습니다. `MidMeshBuilder.AddTube`의 단면 비틀림과 능선, `Mid_CreatureBark.shader`의 거친 목재 표면을 사용합니다.
- 호흡은 약 4.5초 주기이며 전후 굽힘 3.2도, 좌우 흔들림 0.9도, 팽창 2.8%입니다. 상체와 눈에 같은 직접 행렬 변환을 적용하고 하체는 고정합니다. Play 종료 시 원본 메시 참조를 복원하므로 반복 실행해도 변형이 누적되지 않습니다.
- 보행은 실제 이동 거리에 따라 발걸음 위상을 계산합니다. 가감속, 작은 전진 속도 변화, 상하 약 2.7cm/좌우 약 1.3cm의 시점 움직임과 미세한 기울기, 코드로 합성한 발소리를 추가했습니다. 멈추거나 벽에 막히면 발걸음도 멈춥니다.
- `MidProximityStatic`과 `Mid_ScreenStatic.shader`: 5.5m 안쪽에서 약 0.16초짜리 잡음·주사선이 간헐적으로 나타납니다. 가까워질수록 강도가 증가하고 간격은 약 3.8초에서 1.65초로 줄어듭니다. 입력을 가로채지 않는 화면 오버레이이며 장면 UV를 왜곡하는 Renderer Feature는 아닙니다.
- 화면의 제목과 클릭/WASD 안내 텍스트는 모두 제거했습니다. 조작 방법은 아래 문서에만 남겨 둡니다.

## 밝기와 기존 의자 착석

- 별도로 만든 의자 오브젝트와 `Prefabs/Mid_OldChair.prefab`을 삭제했습니다. 정자 원본에 포함된 두 벤치 중 **왼쪽 벤치**를 사용합니다. 원본 FBX는 변경하지 않습니다.
- `MidSceneRevision.MeasureBench`가 기존 좌판의 수평 삼각형을 측정하고, `PositionOnBench`가 골반 최저점과 발 최저점을 좌판/바닥 높이에 맞춥니다. 인체는 -90도 회전해 정자 안쪽을 향합니다. 실측 결과는 `Documentation/BenchPlacement.txt`에 기록합니다.
- 현재 Post Exposure는 0.95, 달빛 강도는 0.65, 차가운 보조 방향광은 0.18입니다. 상부 환경광과 수피 밝기도 높여 나뭇가지를 읽기 쉽게 했습니다. 기존 밤 배경과 차가운 색감은 유지합니다.
- 근거리 크리처 보조광은 최대 5.5이며 착석 위치를 향합니다. 멀리서는 0.25부터 시작해 접근하면 서서히 밝아집니다.
- 별도 의자는 과제 인정 기법으로 계산하지 않았으므로 대체 오브젝트를 추가할 필요가 없습니다. 선택 요소는 기존의 뒤틀린 나무와 떠다니는 불빛으로 유지됩니다.

## 실행

- Unity **6000.3.23f1**, URP **17.3.0**, Input System **1.20.0** 사용. 추가 패키지나 외부 다운로드는 필요하지 않습니다.
- `Assets/Mid/Scenes/TheSilentPavilion.unity`를 열고 Play를 누릅니다.
- Game 화면을 클릭하면 마우스가 고정됩니다. WASD/방향키로 걷고 마우스로 시점을 돌립니다. Esc로 고정을 해제합니다.
- 장면이 없으면 `Tools > Mid > The Silent Pavilion > 01 Open or Create Scene`을 실행합니다.
- `02 Rebuild Generated Scene`은 Mid의 생성 장면/에셋을 재구성합니다. 장면을 직접 수정했다면 먼저 다른 이름으로 저장하세요. 기존 실습 장면/재질/프리팹은 수정하지 않습니다.
- `03 Validate Scene`: 메시·행렬·참조·정자 진입 충돌 경로 검사. 결과는 `Documentation/Validation.txt`에 기록합니다.
- `04 Capture Preview Images`: URP로 외부/내부 미리보기 이미지를 `Documentation`에 저장합니다.
- `05 Apply Lighting and Bench Revision`: 기존 Mid 장면의 다른 배치를 유지하면서 이번 밝기/기존 벤치 착석 보정만 적용합니다. 저장된 장면에는 이미 적용되어 있습니다.
- `06 Apply Branch Creature and Walking`: 기존 환경을 전체 재생성하지 않고 나무형 크리처·보행·잡음 효과를 갱신합니다. 현재 저장된 장면에는 모두 적용되어 있습니다.

|기존 실습 보존|S02–S19 및 ThirdParty 원본|원본 메시/텍스처를 참조하고 Mid 전용 재질을 할당. 원본 실습 장면과 스크립트는 수정하지 않음|

장면에는 기존 의자가 포함된 재사용 정자, 크리처, 나무, 젖은 지면, 물웅덩이, 램프, 떠다니는 불빛, 안개와 먼지가 있습니다. 외부 정자와 목재 텍스처는 환경 재사용이며 직접 Mesh 구현 항목은 크리처와 나무입니다. 선택 요소의 최종 인정 범위는 수업 채점 기준에 따릅니다.

선택 요소는 요청에서 지정한 **추가 기하 모델링 + 추가 변환**입니다. CPU 래스터화/GL 즉시모드는 현재 제출 기법에 포함하지 않습니다. URP Lit·Bloom·안개·기존 정자 재사용은 시각 연출이며, 이를 직접 구현한 필수 기법으로 중복 계산하지 않습니다.

## 원리와 코드 읽는 순서

1. `MidMeshBuilder.AddTube`: Catmull–Rom 곡선 중심 C(t)에 단면 기저 N, B를 두고 `P=C+r(cosθ N+flatten·sinθ B)`를 계산합니다. 나무형 크리처는 경로를 따라 θ를 추가 회전시키고 각도에 따라 r을 변화시켜 꼬임과 능선을 만듭니다. 이전 단면의 법선 방향을 새 접평면으로 투영해 프레임의 갑작스러운 뒤집힘을 줄입니다.
2. `MidCreatureMesh`: 제어점과 반지름을 바꿔 기존 벤치에 앉는 가지 크리처를 구성합니다. 메시는 Editor 생성 시 에셋으로 저장되어 장면을 다시 열어도 남습니다.
3. `MidMatrixMath`: 행과 열의 내적을 반복문으로 계산합니다. 동차좌표 w=1이 이동 항을 적용하게 합니다.
4. `MidCreatureBreathing`: `M=T(pivot)·Rz·Rx·S·T(-pivot)`. 매 프레임 원본 정점에 적용해 변형 누적을 막고, 런타임 메시 복제본만 수정합니다. 눈의 정점도 같은 행렬로 변환합니다.
5. `MidWispMotion`: `x=r cosθ`, `z=.55r sinθ`, `y=.18 sin(1.7θ)`로 별도 운동을 구현합니다.
6. `MidAtmosphere`: 거리 기반 목표 밝기를 시간에 따라 천천히 따라가며 크리처를 드러냅니다. 조명 깜빡임과 눈 Emission도 여기서 제어합니다.
7. `MidFirstPersonController.SimulateMovement`: 실제 이동 거리를 보폭으로 나누어 위상을 누적하고 시점 흔들림과 발소리를 동기화합니다. `MakeFootstep`은 잡음과 감쇠하는 저주파 파형으로 짧은 발소리를 합성합니다.
8. `MidProximityStatic`: 거리로 강도와 재발 간격을 계산하고, 짧은 사인 포락선으로 잡음을 켰다 끕니다. 잡음 셰이더는 해시 노이즈·주사선·수평 띠를 투명 합성합니다.

## 환경과 재사용

- 원본: `Assets/ThirdParty/Pavilion/Prefabs/Pavilion.prefab`, `Lamp.prefab`, 기존 목재/지붕 텍스처, 암석 텍스처.
- 참고 원리: S03–S04 Mesh/와인딩, S09 직접 행렬 계산, S10 변환 합성, S13 이후 URP 재질/조명. 기존 실습 코드는 변경하지 않습니다.
- URP Lit 재질, 차가운 달빛/림라이트, 약한 따뜻한 램프, 거리 기반 보조 조명, 전역 지수 안개를 사용합니다.
- `Shaders/Mid_GroundMist.shader`: 월드 좌표 노이즈를 시간에 따라 이동시키는 반투명 수평 안개 층입니다. 볼류메트릭 레이마칭은 아닙니다.
- 별도 VolumeProfile에 Bloom, ACES, 대비/채도, Vignette를 저장합니다. 프로젝트의 공용 URP 설정을 덮어쓰지 않습니다.
- `Mid_CreatureBark.shader`는 목재 텍스처 명도와 절차적 세로 홈으로 표면 색을 구성하고 URP의 PBR 함수를 이용해 조명·그림자를 받습니다. 전체 PBR 계산을 직접 구현했다고 계산하지 않습니다.

## 검증 범위와 확인할 부분

- 2026-11-08: 실제 Unity 6000.3.23f1에서 자동 배치·장면 저장과 검사 실행 완료. `Documentation/Validation.txt`에 직접 행렬 검산, 메시 인덱스/면적 검사, 원본 정자 크기, 바깥→내부 CharacterController 이동 결과를 기록했습니다.
- 최신 실제 Play 검사: 머리 이동 폭 약 0.140m(모델 좌표), 최대 시점 변화 약 0.0276m, 발걸음 19회, 잡음 4회. 근거리에서도 잡음이 없는 프레임을 확인해 짧게 끝나는 효과임을 검사했습니다. 결과는 `Documentation/PlayModeValidation.txt`입니다. 사람이 키보드/마우스를 조작한 검사는 아니며 실제 보행 컨트롤러의 `SimulateMovement`를 호출해 이동·보행 주기를 검사했습니다. 발소리 생성·호출은 확인했으며 청감 평가는 직접 확인이 필요합니다.
- 그래픽 출력을 켠 URP 렌더 이미지: `Documentation/Preview_Approach.png`, `Preview_Interior.png`, `Preview_Forest.png`. `Preview_MotionA.png`와 `Preview_MotionB.png`는 같은 시점에서 반대 호흡 위상의 모습을 보여줍니다. PNG는 sRGB로 저장합니다. 내부 이미지는 접근 후 보조 조명이 켜진 상태를 재현합니다.
- 실제 검증 결과는 `Documentation`의 보고서와 실행 로그를 기준으로 확인합니다. 코드 컴파일과 실제 렌더링/플레이 검증은 서로 다릅니다.
- 최종 화면 밝기는 디스플레이/해상도에 따라 확인이 필요합니다. 너무 어두우면 Mid 전용 Volume의 Post Exposure 또는 보조 조명 밝기를 조절합니다.
- 물웅덩이는 부드러운 반사 재질이며 평면 반사 카메라/SSR을 구현하지 않았습니다.
- 크리처는 절차적 가지 표면 여러 개가 겹치는 구조이며, 단일 스킨드 메시나 리깅 모델은 아닙니다.
- 안개 평면에는 투명 정렬의 한계가 있습니다. 볼류메트릭 조명, 환경 공간음향, 퀘스트는 기말 확장 항목입니다. 현재 오디오는 보행 발소리입니다.

## 기말 확장 계획

- 추가 오브젝트: 바람에 흔들리는 부적/풍경, 제단과 촛불, 숲길 안내석 중 2개 이상.
- 조명 셰이더: S19 Phong을 확장한 피부/젖은 목재용 직접 조명 계산과 림 조명.
- 곡선·곡면: 곡선 제어점을 편집하는 목/손가락 생성 도구와 곡면 법선 계산 개선.
- 확장 URP: Renderer Feature를 이용한 깊이 기반 안개·화면 효과, 품질별 성능 비교.
- 심화 콘텐츠: 공간 음향, 가까이 볼 때의 시선 반응, 조용한 탐색 목표와 상호작용.

## 1분 이내 소개 영상

- 0–10초: 숲속 정자 외부 실루엣. 제목은 필요한 경우 영상 편집에서 추가합니다.
- 10–28초: WASD로 천천히 정자에 진입하며 크리처가 드러나는 모습.
- 28–40초: 기존 벤치 착석, 가지 형태와 호흡/흔들림, 짧은 접근 잡음 촬영.
- 40–50초: 뒤틀린 나무와 떠다니는 불빛의 독립 운동.
- 50–60초: 반복문 Mesh 생성과 직접 행렬 변환 함수 및 요구사항 표를 짧게 제시.
